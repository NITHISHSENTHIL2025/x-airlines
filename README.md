# 📖 Overview

X Airlines is a modern frontend airline reservation platform developed using **React.js**.

The application simulates a realistic airline booking experience by allowing users to search flights, select seats, enter passenger information, complete payment simulation, and generate boarding passes.

The project was developed as part of a frontend learning journey to explore modern React development practices, reusable component architecture, client-side routing, and browser-based data persistence.

# 💻 Local Installation

Clone the repository

```bash
git clone https://github.com/yourusername/x-airlines.git
```

Navigate to project folder

```bash
cd x-airlines
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

X Airlines is an educational frontend demonstration project.

Flight schedules, booking information, payments, and authentication mechanisms are simulated exclusively for learning and portfolio purposes.

The application is not connected to real airline systems, payment gateways, or production databases.
