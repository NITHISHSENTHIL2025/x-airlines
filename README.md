# ✈️ X Airlines

X Airlines is a modern airline booking frontend application built with React and Vite.

The project simulates a realistic airline booking experience, including user account management, flight search, seat selection, booking confirmation, boarding pass generation, customer support, and legal information pages.

---

## Project Overview

This application focuses on frontend architecture, user experience, component reusability, state management, and multi-step workflow implementation.

While the project does not use a backend or real airline services, it demonstrates the development of a complete frontend application with structured navigation, dynamic interfaces, form handling, and persistent client-side data management.
